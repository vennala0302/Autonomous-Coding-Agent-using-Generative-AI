# Autonomous Coding Agent using Generative AI

## Project Description
The Autonomous Coding Agent is an AI-powered coding assistant developed using Python, Streamlit, and the Google Gemini API. It converts natural language prompts into executable Python code and provides intelligent code analysis features.

## Features
- Generate Python code from user prompts
- Execute generated code
- Explain the generated code
- Debug code
- Optimize code
- Review code quality
- Analyze time and space complexity
- Generate test cases
- User-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Prompt Engineering

## Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/Autonomous-Coding-Agent.git
```

2. Install the required packages:
```bash
pip install -r requirements.txt
```

3. Add your Google Gemini API key.

4. Run the application:
```bash
streamlit run app.py
```
